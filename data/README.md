## Dataset

- **Nombre**: IDB Projects Dataset
- **Fuente**: Banco Interamericano de Desarrollo (BID) — Open Data Portal
- **URL**: https://data.iadb.org/dataset/idb-projects-dataset
- **Licencia**: Creative Commons Attribution 4.0 International (CC BY 4.0)
- **Descripción**: Listado comprehensivo de proyectos del BID (préstamos, garantías, cooperación técnica, etc.) desde 1960 hasta la actualidad, para los 26 países miembros prestatarios.
- **Cita sugerida**: Inter-American Development Bank (2026). IDB Projects Dataset. IDB Open Data. https://doi.org/10.60966/ihisavwe
- **Cómo obtenerlo**: `python data/download_data.py`
